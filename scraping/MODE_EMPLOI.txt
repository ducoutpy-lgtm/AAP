CONTEXTE DU PROJET
------------------
ARCADIA SASU développe une plateforme appelée "AAP Santé" pour aider les
établissements de santé (hôpitaux, EHPAD, IME, etc.) à trouver des financements
appelés "Appels à Projets" (AAP). Ces financements sont publiés sur de nombreux
sites différents (Fondation de France, ARS, CNSA, etc.) et il est très difficile
de les suivre manuellement.

Ce POC (Preuve de Concept) valide que l'on peut automatiser cette collecte.

CE QUE FAIT CE LOGICIEL
-----------------------
1. Il ouvre automatiquement un navigateur (comme vous le feriez à la main).
2. Il parcourt les pages d'un site listant des AAP.
3. Pour chaque AAP trouvé, il ouvre la page et lit le contenu.
4. Il demande à l'intelligence artificielle Claude (Anthropic) d'extraire les
   informations clés : titre, date limite, montant, qui peut candidater, etc.
5. Il sauvegarde tout dans un fichier JSON (un format de données structurées).
6. Il télécharge les pièces jointes (PDF, DOCX) associées à chaque AAP.

RÉSULTAT MESURÉ (au 18 juin 2026)
------------------------------------
- 23 AAP extraits au total (5 Fondation de France + 18 ARS Île-de-France)
- Coût moyen : 0,031 € par AAP extrait
- Coût total tests et développement : ~5,19 €
- 2 sources opérationnelles sur 5 prévues


================================================================================
  GLOSSAIRE — TERMES TECHNIQUES EXPLIQUÉS SIMPLEMENT
================================================================================

Terme          | Ce que ça veut dire en pratique
---------------|------------------------------------------------------------------
Python         | Le langage de programmation utilisé. Comme un moteur de voiture :
               | vous n'avez pas besoin de comprendre le moteur pour conduire.
Venv (.venv)   | Un "espace isolé" pour les outils Python de CE projet.
               | Évite les conflits avec d'autres projets sur votre ordinateur.
Playwright     | La librairie qui pilote le navigateur automatiquement.
               | C'est le "robot" qui clique et lit les pages web à votre place.
Claude API     | L'intelligence artificielle d'Anthropic qu'on appelle pour
               | extraire les infos structurées depuis le texte des pages.
Clé API        | Un mot de passe unique qui autorise votre programme à utiliser
               | l'IA Claude. Elle coûte de l'argent à l'utilisation.
JSON           | Format de données structurées (comme un tableau Excel, mais
               | en texte, lisible par les machines).
JSONL          | Même chose mais une entrée par ligne (pour les journaux).
Git            | Outil de versionnement : garde l'historique de toutes les
               | modifications du code. Comme "l'historique de versions" Word
               | mais pour le code.
Commit         | Une "sauvegarde nommée" dans Git. Chaque commit = une étape
               | de travail enregistrée avec une description.
Cache inter-runs| Mémoire entre deux lancements : si un AAP a déjà été extrait,
               | on ne redemande pas à l'IA. Économise ~95% des coûts API.
Source         | Un site web dont on extrait les AAP. Chaque source = un fichier
               | Python dans sources/
403 Forbidden  | Message du serveur signifiant "accès refusé". Certains sites
               | bloquent les téléchargements de fichiers si vous ne passez pas
               | par un vrai navigateur. Playwright contourne ce blocage.

================================================================================
  LES 4 OUTILS EN DÉTAIL
================================================================================

POURQUOI 4 OUTILS SÉPARÉS ET PAS UN SEUL ?
-------------------------------------------
C'est un choix délibéré pour 5 raisons :
1. Rythmes différents : run.py tournera automatiquement chaque jour en prod.
   validate.py est une relecture HUMAINE, faite quand on le décide.
2. Isolation des pannes : si validate.py a un bug, run.py continue de fonctionner.
3. Développement rapide : quand on teste une nouvelle source, on relance
   run.py 20 fois. Générer un rapport HTML à chaque fois = perte de temps.
4. Formats différents : run.py produit du JSON (pour les machines),
   validate.py produit du HTML (pour les humains dans un navigateur).
5. La validation changera en prod : elle passera par un back-office web,
   pas par ce script HTML temporaire.

Si vous voulez quand même "tout en une commande", vous pouvez enchaîner dans
le terminal VS Code :
   .\.venv\Scripts\python.exe run.py --source ars_idf ; .\.venv\Scripts\python.exe validate.py --source ars_idf


--------------------------------------------------------------------------------
  OUTIL 1 — run.py : LE SCRAPER
--------------------------------------------------------------------------------

QUOI : extrait les AAP d'un site, les fait analyser par l'IA, sauvegarde en JSON.

COMMANDE DE BASE
   .\.venv\Scripts\python.exe run.py --source fondation_de_france
   .\.venv\Scripts\python.exe run.py --source ars_idf

COMMANDE POUR LIMITER LE NOMBRE D'AAP (tests)
   $env:MAX_AAPS=5; .\.venv\Scripts\python.exe run.py --source ars_idf

FORCER UNE RÉ-EXTRACTION COMPLÈTE (repart de zéro, attention au coût)
   $env:FORCE_REFRESH=1; .\.venv\Scripts\python.exe run.py --source ars_idf

LE CACHE INTER-RUNS (économie majeure — lisez bien)
   Au 2e lancement et au-delà, les AAP déjà extraits sont servis depuis
   le fichier results\ars_idf.json SANS rappeler l'IA Claude.
   En régime normal (5% de nouveaux AAP par jour), on économise ~95% du coût.

   Exemple concret :
   - Run 1 : 18 AAP à extraire → 18 appels à Claude → ~0,56 €
   - Run 2 (le lendemain) : 1 nouvel AAP → 1 appel à Claude → ~0,03 €

FICHIERS PRODUITS
   results\ars_idf.json        <- les AAP extraits (format JSON)
   results\ars_idf.errors.json <- les AAP en échec (pour diagnostic)
   downloads\ars_idf\          <- PDF téléchargés via Playwright
   logs\extraction_costs.jsonl <- 1 ligne par appel IA (coût, tokens)

NOTE SUR LES PDF DE L'ARS IDF
   Le site ARS Île-de-France bloque les téléchargements directs de fichiers
   (erreur 403 = accès refusé). Le scraper utilise Playwright (le vrai
   navigateur) pour contourner ce blocage — comme si un humain cliquait.
   C'est normal et intentionnel.

CE QU'ON VOIT DANS LE RAPPORT
   - Chaque AAP sur une ligne : champs extraits à gauche, page source à droite
   - Score /10 par AAP (vert = bon, rouge = problème)
   - Pastille par champ : vert = rempli, rouge = manquant, orange = partiel
   - Un sommaire cliquable en haut de page

COMMENT RELIRE (10-15 min pour 50 AAP)
   1. Regarder d'abord les AAP avec score < 5/10
   2. Pour chaque champ manquant : regarder la page source à droite.
      - L'info n'est PAS sur la page → normal, rien à faire
      - L'info EST sur la page mais non extraite → problème à noter
   3. Les champs "catégories établissement" vides sur la Fondation de France
      sont normaux : cette source ne cible pas des établissements spécifiques.

   - Proposition des commits Git

================================================================================
  PROBLÈMES COURANTS ET SOLUTIONS
================================================================================

Symptôme : "ModuleNotFoundError: No module named 'anthropic'"
   Cause : l'environnement Python n'est pas activé
   Solution : taper .\.venv\Scripts\activate (vérifier que (.venv) apparaît)

Symptôme : "ANTHROPIC_API_KEY manquante"
   Cause : le fichier .env n'existe pas ou la clé est manquante
   Solution 1 : vérifier que le fichier .env existe (copy .env.example .env)
   Solution 2 : ouvrir .env avec notepad et vérifier que la clé est présente

Symptôme : "529 Overloaded" ou "429 rate_limit"
   Cause : l'API Claude est surchargée ou vous avez dépassé un quota
   Solution : le retry automatique est en place (4 tentatives). Si ça persiste,
              attendre 10 minutes et relancer.

Symptôme : "0 URLs candidates trouvées"
   Cause : le site a changé sa structure HTML, ou le filtre CSS est trop strict
   Solution : lancer debug_page.py sur la page de listing, examiner links.txt

Symptôme : "[pdf echec] 403 Forbidden"
   Cause : le site bloque les téléchargements de fichiers aux robots
   Solution : vérifier que le scraper utilise page.expect_download() et non
              httpx (voir sources\ars_idf.py comme exemple de contournement)

Symptôme : tous les AAP sont en erreur "texte_trop_court"
   Cause : le contenu est chargé en JavaScript après le chargement initial
   Solution : augmenter le timeout dans fetch_detail() dans le fichier source :
              await page.wait_for_timeout(3000)  # attendre 3 secondes de plus

Symptôme : "Fichier introuvable : results\ars_idf.json" dans validate.py
   Cause : le scraper n'a pas encore tourné, ou le fichier a été supprimé
   Solution : lancer d'abord run.py --source ars_idf

Symptôme : coût inattendu élevé
   Solution : .\.venv\Scripts\python.exe analyze_costs.py --today
              Le cache inter-runs est actif par défaut, donc le coût doit être
              faible sauf si c'est le premier run ou si FORCE_REFRESH est actif.


================================================================================
  FAQ — QUESTIONS FRÉQUENTES
================================================================================

Où changer ma clé API Anthropic ?
   Ouvrir le fichier poc-scraping\.env avec le Bloc-notes et modifier la ligne :
   ANTHROPIC_API_KEY=sk-ant-api03-votre-nouvelle-cle

Comment voir combien j'ai dépensé en API Claude ce mois-ci ?
   .\.venv\Scripts\python.exe analyze_costs.py
   (voir aussi le tableau de bord sur https://console.anthropic.com/)

Où sont les AAP extraits ?
   Dans poc-scraping\results\ars_idf.json
   C'est un fichier texte JSON que vous pouvez ouvrir dans VS Code en cliquant
   dessus dans le panneau gauche.

Comment ouvrir le rapport HTML après validate.py ?
   Dans VS Code, panneau gauche → validation_reports → clic droit sur le fichier
   → "Reveal in File Explorer" → double-clic dans l'explorateur Windows.

Comment savoir si le cache fonctionne bien ?
   Au 2e run, vous verrez des lignes "[cache] ..." au lieu de "[Claude] ..."
   Et la commande analyze_costs.py --today ne montrera aucun nouveau coût.

Pourquoi le scraper ARS IDF télécharge-t-il les PDF différemment ?
   Le site ARS bloque les téléchargements directs (erreur 403). Le scraper
   utilise Playwright (le navigateur) pour télécharger, comme un vrai humain.
   C'est la méthode dans sources\ars_idf.py avec page.expect_download().

Peut-on utiliser Gemini (Google) à la place de Claude (Anthropic) ?
   Non, pas sans modifier le code (2-3h de travail). Et ce n'est pas recommandé
   pour l'instant : le coût est déjà sous le seuil acceptable (0,031 €/AAP),
   et l'extraction structurée en français est fiable chez Anthropic.
   Réévaluer si le coût dépasse 500 €/mois en production.

Comment modifier le format des données extraites (ajouter un champ) ?
   Modifier poc-scraping\schema.py (la structure de données)
   ET poc-scraping\extractor.py (le prompt qui dit à Claude quoi extraire)
   ATTENTION : ce changement invalide le cache. Il faudra relancer avec
   FORCE_REFRESH=1 pour tout ré-extraire avec le nouveau format.

Pourquoi le score /10 de certains AAP est bas ?
   Souvent parce que l'AAP ne précise pas certains champs sur sa page
